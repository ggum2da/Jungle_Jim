# Jungle_Jim — 게임 개요 및 프로젝트 계약

> 버전 1.0 · 작성일 2026-11-05 · 상태: 구현을 위한 제안 기준선
> 대상: 기획·프로그래밍·아트·QA 및 이 문서를 읽는 Codex

## 1. 문서의 출처와 읽는 방법

참조 대화: 「외계 침공 이야기」, 대화 ID `6aec7f6a-b838-83ee-bda5-8b5b0659c652`.
원문의 전체 이야기와 후속 게임 기획을 확인하고 작성했다. 이 패키지는 기존 게임 코드나 엔진을 조사한 결과가 아니다.

- **원작 고정 설정**: 2042년, 아마존, 강태건과 주요 동료 4명, 외계 군집, 배신과 희생, 선발대 반전, 변이 에필로그.
- **게임화 제안**: 시점·조작·수치·레벨 규모·연출 시간·기술 구조·일정. 기존 프로젝트에 해당 기능이 있다는 의미가 아니다.
- 수치표의 값은 플레이테스트 전 초기값이다. 변경할 때 관련 문서와 데이터도 함께 바꾼다.
- 기존 프로젝트를 먼저 확인하고 엔진, 좌표계, 입력 체계, 저장 형식을 존중한다. 확인 없이 프로젝트를 새 엔진으로 전환하지 않는다.
- 모든 문서에는 스포일러가 있다. 플레이어에게 공개하는 소개글과 분리한다.

## 2. 제품 정의

| 항목 | 기준 |
|---|---|
| 정식 표기 | `Jungle_Jim` |
| 부제 | Fallen Earth / 추락한 지구 |
| 장르 | 싱글플레이 SF 밀리터리 슈팅 액션·서바이벌 |
| 배경 | 2042년 8월, 외계 생태계에 잠식되는 아마존 |
| 플레이어 | 강태건, 42세 전직 대한민국 특수전사령부·다국적 부대 스펙터 지휘관 |
| 시점 제안 | 어깨 너머 3인칭, 조준 시 카메라 확대 |
| 우선 플랫폼 | 데스크톱 PC, 키보드·마우스; 다른 플랫폼은 후속 검토 |
| 진행 | 프롤로그 + 5개 선형 챕터 + 엔딩·에필로그 |
| 캠페인 목표 길이 | 첫 플레이 보통 난도 약 125~160분; 영상 포함, 선택 탐색에 따라 변동 |
| MVP 길이 | CH01 완결 10~15분; 전체 캠페인과 별도 검수 |
| 목표 경험 | 추락의 무력감 → 습성 학습 → 군집의 연결을 역이용 → 희생과 미완의 승리 |

한 문장 피치: 외계 포식자에게 격추된 베테랑 군인이 정글의 자원과 적의 신호 체계를 이용해 모체의 신경망을 끊는 이야기 중심 슈팅 게임.

## 3. 핵심 재미와 구현 원칙

| 원칙 | 플레이에서 보이는 결과 | 검수 증거 |
|---|---|---|
| 사냥당하다 사냥한다 | 첫 Stalker는 기습, 이후 위장 흔적을 알아보고 선제 사격 | CH01에서 흔적→출현→약점 명중을 경험 |
| 사격 결과가 분명하다 | 장갑과 약점의 소리·불꽃·반응이 다름 | 같은 소총으로 두 부위를 쐈을 때 구별 가능 |
| 정글은 전술 공간이다 | 엄폐물, 우회로, 높은 둑, 미리 정한 환경 함정 | CH02 전투에 최소 2개 진입로 |
| 공포에도 대응 수단이 있다 | 공격 예고, 발광 기관, 음향·자막 단서 | 어둠 속에서도 피격 전 적의 단서를 확인 |
| 서사가 행동을 바꾼다 | 조직 분석→장갑 약점, 군집 해독→교란기 | 해금 직후 해당 기능을 쓰는 전투 배치 |

핵심 루프: **탐색 → 단서·자원 발견 → 위협 판독 → 교전 또는 우회 → 목표 달성 → 안전 구간·체크포인트 → 새 위협**.
메타 루프는 챕터 해금과 장비 획득으로 한정한다. 반복 파밍이나 레벨 수치 상승을 요구하지 않는다.

## 4. 서사·챕터의 고정 골격

| 게임 챕터 | 핵심 사건 | 원작 이야기의 대응 구간 |
|---|---|---|
| CH01 추락 / The Crash | BLACK HAWK 격추, 장비 확보, 첫 Stalker, 집결 | 프롤로그·원작 1~3장 |
| CH02 사냥터 / Hunting Ground | 생존자 구조, Stalker 무리, 군집과 생포 흔적 | 원작 3~4장 확장 |
| CH03 포식자 / Predators | Brute, 조직 분석, Wraith와 교란원 제거 | 원작 4장 게임화 |
| CH04 고대의 비밀 / Ancient Secret | 고대 유적, 남극 연구·15년 전 신호·3년 전 참사, 마커스 희생 | 원작 5~6장 |
| CH05 최후의 사냥 / Final Hunt | 교란기, Overseer, Mother Core, 7분, 희생·에필로그 | 원작 7~9장·에필로그 |

게임 챕터 수를 원작 이야기의 9장과 혼동하지 않는다. CH05의 승리는 중앙 연결망의 붕괴와 생태계 전환 저지이며, 모든 외계 개체의 영구 절멸을 뜻하지 않는다.

MVP에서 나머지 4개 챕터를 빈 껍데기로 추가하지 않는다. MVP 합격 후 캠페인을 확장한다. 실제 전투가 없는 CH01 Wraith는 실루엣·애니메이션 연출로만 등장한다.

## 6. 공통 실행·접근성 기준

- 기본 난도는 보통 하나. 체력·탄약·자막·체크포인트를 명확하게 표시한다.
- 텍스트는 한국어 UTF-8, 대사 화자 표시, 1080p에서 본문 20px 상당 이상을 권장한다.
- 마우스 감도·음량·자막·화면 흔들림·동작 흐림을 조절한다. 컷신 건너뛰기와 일시정지 제공.
- 필수 공격 예고와 상호작용은 색 하나에 의존하지 않는다. 모양·소리·문자 중 보조 수단 제공.
- 미션 진행에 동료 생존 AI나 필수 아이템의 물리 낙하가 영향을 주지 않게 설계한다.
- 저장 실패는 사용자에게 알리고 재시도 수단을 준다. 실패한 저장을 정상 체크포인트로 표시하지 않는다.
- 성능 목표: 기준 PC를 확정한 뒤 1080p 보통 옵션 60fps. 미확정 단계에서는 달성했다고 보고하지 않는다.

## 8. 승인 가능한 결과물

### MVP 합격

새 게임에서 CH01 완료까지 막힘 없이 10~15분 플레이할 수 있다. 적과 싸우고, 회복하고, 사망하고, 재실행 후 체크포인트를 불러올 수 있다. 목표 중복 발생·무한 탄약·벽 관통 사격·진행 불능이 없다. 임시 아트는 표시하고 사용 권리를 기록한다.

### 캠페인 합격

5챕터와 엔딩·에필로그를 순서대로 완료한다. 모든 반전은 공개 시점 이전에 누설하지 않는다. 각 챕터 경계에서 저장·재시작해도 미션과 장비 상태가 일치한다. 최종 빌드와 알려진 문제, 기준 PC의 성능 결과, 에셋 출처를 함께 전달한다.

## 9. Codex의 첫 작업

1. 저장소 구조·엔진 버전·기존 입력·플레이어·적·저장 구현을 확인한다.
2. 현재 기능과 MVP 표를 비교하고 기존 구현을 재사용한다.
3. `07_DEVELOPMENT_PLAN.md`의 P0 순서로 한 가지 플레이 가능한 흐름을 만든다.
4. 변경 파일·실행 방법·검증 결과·남은 제한을 기록한다. 이 문서 패키지만으로 코드 구현이나 테스트가 완료됐다고 보고하지 않는다.
