# Jungle_Jim — 조작·전투·AI·저장 구현 명세

> 버전 1.0 · 모든 수치는 플레이테스트 전 제안값
> 이 문서는 전투 수치와 상태 계약의 기준이다. 특정 엔진의 클래스 구현을 강제하지 않는다.
> 연결: [레벨·보급](04_LEVEL_DESIGN.md) · [완료 기준](07_DEVELOPMENT_PLAN.md)

## 1. 좌표·시간·입력

거리 m, 속도 m/s, 시간 초, 피해 HP를 사용한다. 엔진 단위가 다르면 입출력 경계에서 변환한다. 이동·피해 쿨다운·타이머는 프레임 수에 의존하지 않는다. 게임 시간과 실제 시간을 분리해 일시정지가 전투와 타이머를 모두 멈추게 한다.

| 행동 ID | 기본 입력 제안 | 규칙 |
|---|---|---|
| Move / Look | WASD / 마우스 | 이동 대각선 정규화, 시점 회전 |
| Sprint | Left Shift 유지 | 전방 이동 중, 조준·사격·재장전과 동시 불가 |
| Jump | Space | 지상에서만, 공중 연속 점프 불가 |
| Dodge | Left Alt | 이동 방향, 무입력 시 후방 |
| Aim / Fire | 우클릭 유지 / 좌클릭 | 조준·비조준 사격 가능 |
| Reload | R | 장전 가능·예비탄 존재 시 |
| Interact | E | 거리 2m 이내, 시야 확보, 후보 1개 선택 |
| WeaponSelect | 1~4 / 휠 | 획득 무기만 순환 |
| Heal | Q | 회복약 사용 |
| Grenade | G | 캠페인 확장부터 사용 |
| Disruptor | F | CH05 해금, 지정 장치 또는 보스전에서만 |
| Pause | Esc | 메뉴, 타이머·AI·피해 정지 |

입력은 액션 매핑으로 분리한다. MVP는 기본 배치와 감도 설정을 제공하고 전체 캠페인 완료 단계에서 키 재지정을 검수한다. 컨트롤러 지원은 이번 필수 범위가 아니다.

UI가 입력을 받는 동안 발사가 월드로 전달되지 않는다. 대화·메뉴 종료 후 버튼이 계속 눌린 상태를 잘못 인식해 총이 발사되지 않도록 입력 경계를 정리한다.

## 2. 플레이어 이동과 카메라

| 항목 | 초기값·규칙 |
|---|---|
| 체력 | 최대 100, 자동 재생 없음 |
| 걷기 / 달리기 / 조준 이동 | 4.0 / 6.5 / 2.5m/s |
| 점프 | 높이 약 1m, 지형 건너기용, 연속 공중 점프 없음 |
| 회피 | 3m / 0.45초, 쿨다운 1.5초, 무적 시간 없음 |
| 회피 중 충돌 | 벽·적·지형에 막힘, 이동 스윕으로 관통 방지 |
| 카메라 거리 | 일반 3m, 조준 1.8m |
| 수직 시야각 | 일반 65°, 조준 50°, 설정에서 멀미에 맞춰 조절 가능 |
| 조준 전환 | 0.2초 보간 |
| 카메라 충돌 | 벽 앞에서 거리 축소, 벽 바깥을 보지 않음 |
| 줌 어깨 | 기본 오른쪽, 어깨 전환은 후속 선택 기능 |

엄폐는 벽 뒤로 이동하는 방식이다. 버튼으로 달라붙는 커버 시스템·앉기·엎드리기는 필수가 아니다. 달리기와 회피에 스태미나를 추가하지 않고 회피 쿨다운으로 반복을 제한한다.

### 행동 충돌 우선순위

`사망/최종 연출 > 컷신 > 메뉴 > 피격 경직 > 회피 > 회복/상호작용 > 재장전 > 사격 > 일반 이동`.

- 회피는 재장전을 취소한다. 탄약 이동은 재장전 완료 시 한 번만 적용한다.
- 무기 전환은 재장전·회복을 취소한다. 취소된 회복은 아이템을 소비하지 않는다.
- 피격 시 회복·설치 상호작용을 중단한다. 재장전은 강한 경직 이벤트에만 중단한다.
- 사망 시 발사·타이머 판정·상호작용을 잠근다. 총알이 0이면 재장전 안내를 제공한다.

## 3. 무기 데이터

피해는 기본 난도, 장갑·약점 배율 적용 전 값이다. 사거리는 유효 판정 최대 거리이며 초기 버전에는 거리 감쇠를 넣지 않는다. 소총은 자동, 나머지는 반자동이다.

| ID / 무기 | 탄창 | 예비 상한 | 기본 피해 | 발사 간격 | 재장전 | 사거리 | 해금 |
|---|---:|---:|---:|---:|---:|---:|---|
| W_RIFLE / 돌격소총 | 30 | 180 | 20 | 0.10초 | 2.2초 | 100m | CH01 |
| W_PISTOL / 권총 | 12 | 72 | 24 | 0.25초 | 1.5초 | 45m | 시작 |
| W_SHOTGUN / 산탄총 | 8 | 32 | 12×8펠릿 | 0.85초 | 2.8초 | 25m | CH02 말 |
| W_SNIPER / 저격소총 | 5 | 25 | 100 | 1.2초 | 3.0초 | 150m | CH03 분석 후 |
| W_GRENADE / 수류탄 | 해당 없음 | 3개 | 중심 160 | 투척 쿨다운 1초 | 없음 | 투척속도 14m/s | CH03 |

- 총기는 히트스캔을 기본으로 한다. 총구 섬광·탄피·예광은 피드백이며 실제 판정과 분리한다.
- 총알 판정: 화면 중앙에서 조준 지점을 구하고, **총구에서 그 지점까지 다시 충돌 검사**한다. 카메라가 벽 너머를 보더라도 총구가 가려지면 벽에 맞는다.
- 산탄은 조준 시 4°, 비조준 시 7° 원뿔, 펠릿별 독립 충돌. 다른 총기의 조준 분산 0.3°, 비조준 2° 제안. 연속 발사 반동은 카메라 소폭 상승으로 표현하고 외부 입력을 강제 덮어쓰지 않는다.
- 무기 전환 0.4초. 소총·권총만 있는 MVP도 같은 데이터 구조를 사용한다.
- 수류탄은 2.5초 뒤 폭발. 피해 반경 5m, 중심 0~2m는 160, 2~5m는 160→0 선형 감쇠. 벽 차폐 검사 적용. 자기 피해 배율 0.5, 동료 피해 없음.
- 수류탄 장갑 배율은 해당 적의 장갑 규칙을 따른다. 수류탄으로 필수 약점 단계를 건너뛰지 않는다.

### 피해 계산

`최종 피해 = 기본 피해 × 부위 배율 × 방어 상태 배율`.

부위 배율은 일반 몸통 1.0, 적별 약점은 아래 표를 따른다. 하나의 명중이 몸통과 약점에 중복 집계되지 않는다. 일반 외계 머리의 외형만으로 공통 헤드샷 배율을 적용하지 않는다. 노출되지 않은 약점은 장갑 부위로 판정한다. 피해 출처·부위·결과 값을 디버그 화면에서 볼 수 있게 하되 출시 HUD에서는 숨긴다.

## 4. 적 수치와 교전 예산

| 적 | 체력 | 몸통 배율 | 노출 약점 배율 | 주요 피해 | 예고 / 후딜 | 동시 활성 상한 |
|---|---:|---:|---:|---|---|---:|
| Stalker | 100 | 1.0 | 1.5 | 도약 18 | 0.8 / 1.2초 | MVP 2, 캠페인 4 |
| Brute | 1,200 | 장갑 0.15 | 2.0 | 돌진 35, 내려찍기 30 | 1.6 / 2.5초 | 1 |
| Wraith | 900 | 0.5 | 2.0 | 급강하 25 | 1.5 / 노출 3초 | 1 |
| Overseer | 1,500 | 0.4 | 2.0 | 직선 25, 근접 20 | 1.2 / 1.5초 | 보스 1+Stalker 최대 4 |
| Mother Core | 노드당 300×3 | 비노드 무효 | 노드 1.0 | 촉수 20, 파동 15 | 1.5 / 1.5초 | 중추 1+Stalker 최대 4 |

노출 약점에 몸통 장갑 배율을 다시 곱하지 않는다. 예: Brute 약점 소총 1발은 `20×2.0=40`, 장갑은 `20×0.15=3`. Mother Core는 노드당 소총 15발, 3노드 최소 45발이다. 연출상 거대한 코어 외벽에는 무효 피드백을 표시한다.

**탄약 검토 예:** Stalker 몸통은 소총 5발, CH01 세 마리는 최소 15발. Brute는 약점 전탄 명중 시 30발, Wraith는 23발, Overseer는 최소 38발이지만 단계 잠금과 증원 때문에 추가 탄약이 필요하다. 명중률 40~50%와 증원을 고려한 상자 수를 레벨 문서에서 보장하고 플레이테스트로 조정한다. 보스 체력만 늘려 난도를 맞추지 않는다.

Stalker는 한 번 도약에 한 번만 피해를 준다. 플레이어는 피해 후 0.6초 동안 같은 공격자의 추가 피해를 받지 않지만 다른 적의 공격까지 무적은 아니다. 같은 개체의 겹친 콜라이더로 중복 피격되지 않아야 한다.

## 5. AI 공통 상태와 감지

`Idle → Patrol → Suspicious → Chase → AttackWindup → Attack → Recover`를 기본으로 하고 `HitReact / Disrupted / Return / Dead`를 분기한다.

| 항목 | 기본값·규칙 |
|---|---|
| 지상 적 시야 | 거리 25m, 전방 전체 각도 100°, 지형 차폐 검사 |
| 의심 확정 | 시야 안에서 0.4초 유지하면 추적; 근접 5m는 0.15초 |
| 청각 | 소총 35m, 권총 25m, 달리기 10m; 이벤트 위치로 이동 |
| 시야 상실 | 마지막 위치 3초 탐색 후 주변 5초 탐색, 실패하면 복귀 |
| 공격 슬롯 | 일반 근접 적 최대 2마리만 동시 예고, 나머지는 측면 이동 |
| 경로 재계산 | 목표 이동 시, 최대 0.5초에 1회 제안 |
| 정체 복구 | 추적 중 5초간 0.5m 미만 이동 시 복구 경로 요청 |
| 사망 | 피해·공격·이동 중지, 미션 처치 이벤트 1회 발행 |

어둠·비·수풀에 따른 복잡한 가시성 수치는 MVP에서 제외한다. 인지했는지와 공격 준비 여부는 자세·음향으로 피드백한다. 적이 플레이어의 입력이나 보이지 않는 위치를 직접 읽어 즉시 공격하지 않는다.

Stalker의 위장은 지정 나무 앵커에서만 켠다. 의심 시 미세한 움직임이 보이고 공격 0.8초 전에는 위장을 푼다. 공중 도약은 시작·착지점 고정 후 제한적인 보간으로 처리하며, 도약 중 플레이어를 완벽 추적하지 않는다.

## 6. 보스별 상태 계약

### Brute

1. 장갑 상태로 접근한다.
2. 1.6초 몸 낮추기로 돌진 예고, 지면에 경로 표시.
3. 돌진 방향은 출발 때 확정한다. 암석·지정 엄폐 충돌 후 2.5초 관절·등 기관 노출.
4. 근접 플레이어에게 내려찍기, 빗나간 뒤에도 노출 기회를 준다.
5. 체력 50% 아래에서 돌진 간격을 6초→4.5초로 줄이되 예고 시간은 유지한다.

### Wraith

`상공 선회 5초 → 교란 발광 1.5초 → 급강하 → 낮은 활공 3초` 반복. 저격 기회는 활공 중 가슴 기관이다. 체력 50% 이하에서 다음 경로를 교대로 선택한다. 조준점·입력·HUD를 무작위 흔들지 않는다. 격추 시 연출 종료를 기다리지 않고 처치 상태를 먼저 확정한다.

### Overseer

- P1: HP 1,500→1,000. 기본 공격과 Stalker 2마리 호출 1회.
- 1,000 도달 시 추가 피해 잠금, 윤아의 신호 기관 저격 이벤트. 기관 5초 노출. 한 발 이상 명중하면 P2.
- P2: HP 1,000→500. 측면 호출 2마리 1회, 직선 타격. 플레이어는 교란기를 한 번 작동시켜 보호막을 해제해야 한다.
- 500 도달 시 P3 조건을 확인한다. 교란기가 미사용이면 공격을 계속할 수 있으나 체력은 500 아래로 내려가지 않고 사용 안내를 준다.
- P3: HP 500→0. 근접 휩쓸기와 직선 공격 교대, 추가 소환 없음. 사망 후 코어 통로 개방.
- 강한 단일 공격이 경계 체력을 넘더라도 단계별 해금 없이 보스를 처치하지 못한다. 이벤트와 체력 잠금은 코드 한 곳에서 처리한다.

### Mother Core

교란기 준비 완료 후 작전을 시작한다. 노드 1개가 노출되고, 파괴하면 다음 노드가 노출된다. 각 노드 사이 Stalker 2마리 소환, 총 4마리. 촉수는 플레이어의 현재 위치를 예고 시작 때 기록하고 1.5초 뒤 그 지점을 공격한다. 파동은 낮은 지형 장애물 뒤로 피할 수 있다. 뛰어넘기를 필수로 하지 않는다.

3개 노드 파괴 후 최종 설치 지점 활성화. 설치는 3초 연속 유지, 피격 시 진행 0으로 초기화. 설치 완료는 성공 상태를 원자적으로 기록하고 전투·타이머·피해를 중단한다. 이후 타격·실종·에필로그는 [02_STORY.md](02_STORY.md)의 연출이다.

## 7. 교란기·환경 함정

교란기: CH05 전용, 유효 반경 20m, 효과 5초, 쿨다운 25초, 사용 횟수 제한 없음. Stalker는 방향을 잃고 공격을 취소한다. Overseer는 보호막을 벗고 다음 공격이 지연된다. Mother Core에서는 작전 시작 장치의 역할이며 반복 사용으로 노드 순서를 건너뛰지 않는다. 자동으로 적을 처치하지 않는다.

환경 함정: 지정 매달린 잔해 고정 장치 HP 40, 파괴 시 표시된 4m 영역에 200 피해. 플레이어도 50 피해, 동료 무피해. 1회 사용 후 재생성하지 않는다. MVP 제외, CH05 협곡에서 1곳으로 시작한다. 일반 배경 나무를 쏠 때 같은 결과를 기대하게 만들지 않는다.

## 8. 회복·인벤토리·HUD

회복약 최대 3개, 2초 사용 후 40 회복, 최대 체력 초과분은 버린다. 체력이 가득 차면 사용하지 않는다. 체력이 0이면 회복 입력을 무시한다. 아이템 소비와 회복 적용은 완료 시 한 번만 처리한다.

인벤토리는 획득 무기 목록·무기별 장전/예비탄·회복약·수류탄·퀘스트 플래그만 보유한다. 무게·칸 정리·아이템 등급은 없다. 상자 획득은 상한까지 채우고 남은 수량을 상자에 보존한다. 전부 수령한 경우에만 소진 상태를 저장한다.

HUD: 체력, 장전/예비탄, 무기명, 회복약/수류탄 수량, 현재 목표 1개, 목표 거리, 상호작용 안내, 교란기 쿨다운. 보스전에는 체력·약점 노출 상태·노드 카운터·최종 7분을 추가한다. 총알 장갑 명중과 약점 명중은 서로 다른 표시·소리로 구분한다.

## 9. 체크포인트·영속 데이터

MVP는 로컬 단일 슬롯. 저장 키는 표시 문자열과 분리한다. 저장 중에는 임시 파일에 쓴 뒤 교체해 중단 시 손상을 줄인다. 버전 불일치·파싱 실패 시 기존 파일을 백업하고 새 게임 또는 마지막 유효 저장을 선택할 수 있게 한다. 앱을 종료할 때 무조건 현재 위치를 저장하지 않는다.

예시 구조는 엔진 중립 데이터 계약이며 JSON 저장을 강제하지 않는다.

```json
{
  "schemaVersion": 1,
  "chapterId": "CH01",
  "checkpointId": "CP_C01_02",
  "health": 100,
  "inventory": {
    "unlockedWeapons": ["W_PISTOL", "W_RIFLE"],
    "equippedWeapon": "W_RIFLE",
    "ammo": {
      "W_PISTOL": {"loaded": 12, "reserve": 36},
      "W_RIFLE": {"loaded": 21, "reserve": 90}
    },
    "medkits": 1,
    "grenades": 0
  },
  "objectives": {"M_C01_04": {"state": "COMPLETED", "count": 3}},
  "completedEvents": ["SC_C01_Mimic"],
  "worldState": {
    "deadEnemyIds": ["C01_ST_01", "C01_ST_02", "C01_ST_03"],
    "pickupRemaining": {"C01_AMMO_01": 0},
    "usedEmergencySupplyIds": []
  },
  "storyFlags": {"medicMissing": true, "marcusDead": false},
  "unlockedChapters": ["CH01"],
  "finalRun": null
}
```

- 플레이어 위치는 임의 좌표 대신 `checkpointId`에 대응하는 안전 앵커로 복원한다. 체크포인트 위치·카메라 방향은 레벨 데이터가 소유한다.
- 로드 순서: 스키마 검증→레벨 로드→체크포인트 장면 구성→완료 이벤트·월드 상태 적용→인벤토리·목표 복원→플레이어 조작 허용.
- 체크포인트 이후 발생한 사망·소모·처치는 재시작 시 모두 롤백한다. 재시작 때마다 무료 회복·탄약을 누적 지급하지 않는다.
- 일반 적의 순간 위치·공격 중간 프레임은 저장하지 않는다. 체크포인트에 정의된 적 배치를 생성하고 저장된 처치 ID를 제외한다.
- CP_C05_02는 `finalRun={remainingSeconds:420,destroyedNodeIds:[]}`를 저장한다. 전투 도중 저장은 하지 않으므로 부분 노드·부분 타이머 복원을 구현할 필요가 없다.
- 최종 성공 저장에는 `campaignCompleted=true`, 타격 완료·에필로그 해금 상태를 함께 기록한다. 저장 실패 시 현재 성공 상태를 유지하고 재시도를 제공한다.
