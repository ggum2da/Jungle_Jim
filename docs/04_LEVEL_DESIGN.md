# Jungle_Jim — 5챕터 레벨·미션 설계

> 버전 1.0 · 공간 수치·동선·배치는 게임화 초기 제안
> 연결: [서사](02_STORY.md) · [전투·저장](05_GAMEPLAY.md) · [작업 검수](07_DEVELOPMENT_PLAN.md)

## 1. 공통 공간·진행 규칙

단위는 m, 소요 시간은 첫 플레이 보통 난도 추정이다. 레벨 크기는 도보 동선의 누적 길이이며 전체 월드의 폭이 아니다. 지도는 독립 레벨 5개로 나누고 챕터 경계에서 다음 맵을 로드한다.

- 기본 통로 폭 3~5m, 측면 우회로 2m 이상, 전투장 진입·퇴출부 4m 이상을 권장한다.
- 플레이어 캡슐 0.4m 반지름·1.8m 높이를 초기 기준으로 잡되 기존 엔진 규격과 맞춘다.
- 플레이어·카메라·Brute의 통과 가능 영역을 별도로 검수한다. 적 스폰 지점은 이동 가능 영역 안에 둔다.
- 수풀은 가시성을 제한하되 필수 길·적의 예고·탄약 아이콘을 완전히 가리지 않는다.
- 고정 보급 상자와 목표 물체는 월드 바깥으로 떨어지지 않는다. 필수 물체를 적의 확률 드롭에 의존시키지 않는다.
- 처음 보는 위협을 안전 구간에서 예고한 뒤 실전 투입한다. 첫 등장부터 복수 신종을 한꺼번에 섞지 않는다.
- 미션 상태는 `LOCKED → ACTIVE → COMPLETED`; 실패는 체크포인트 재시작으로 복원한다. 중간 진행은 목표별 정수 카운터로 저장한다.
- 트리거 ID와 처치 대상 ID는 재로드 후에도 안정적이다. 한 트리거의 재진입이 적과 보급을 중복 생성하지 않게 한다.
- 컷신 시작 전 저장된 상태로 재시작할 때는 컷신을 다시 재생할 수 있고, 완료 후 저장했다면 결과만 복원한다.

### 동선의 문법

`안전·서사 → 관찰 → 전투 → 짧은 탐색·보상 → 새 목표`를 반복한다. 길 찾기는 노란 페인트 하나보다 빛·구조물·지형 방향·목표 거리 표시를 함께 사용한다. 지도 화면은 MVP 필수가 아니며 현재 목표·방향·거리로 진행 가능해야 한다.

## 3. CH01 — 추락 / The Crash

### 공간

`헬기 잔해 A → 장비 보관함 → 임시 치료 지점 → 나무 위장 통로 → 첫 교전 B → 얕은 계류 → 집결지 C`

- A: 약 25×25m. 불길과 잔해로 진행 방향을 안내. 불은 연출 벽이며 지속 피해 함정은 MVP에서 제외.
- B: 약 35×30m. 큰 나무 3개·낮은 잔해 2개·측면 통로. 첫 적과의 거리 15~20m.
- C: 약 20×20m. 교전이 끝난 뒤 안전하게 전환하며 CH02 경로를 보여준다.

### 미션 계약

| ID | 활성 조건 | 행동·완료 조건 | 결과 |
|---|---|---|---|
| M_C01_01 | 추락 연출 종료 | 이동 지점 2곳 통과 | 기본 이동 안내 종료 |
| M_C01_02 | 01 완료 | 고정 상자에서 소총·탄약 획득 | 소총 장착·저장 CP_C01_01 |
| M_C01_03 | 02 완료 | 회복약 상자 획득 후 회복 사용, 준호와 상호작용 | 치료·상호작용 학습 |
| M_C01_04 | 첫 조우 연출 종료 | 지정 Stalker 3마리 처치 | 탈출 통로 개방·CP_C01_02 |
| M_C01_05 | 04 완료 | 집결지에 진입 | CH01 완료·CH02 해금 |

### 전투·학습

처음 한 마리는 정면 출현, 뒤의 2마리는 1마리 처치 후 진입한다. 동시 활성 상한은 2다. 3마리가 모두 죽기 전에 출구가 열리지 않는다. 첫 적은 플레이어가 무기를 획득한 뒤에만 공격한다.

최초 체력은 70/100으로 주어 회복 사용의 의미를 만든다. M_C01_03 이전에는 보급 상자를 다시 사용해 회복약 1개를 보장할 수 있으나 학습 완료 후 재지급하지 않는다. CP_C01_01은 소총 획득과 초기 체력 70 상태를 함께 저장한다.

### 고정 보급

소총 30발 장전+90발 예비, 권총 12+36발, 회복약 2개. 첫 교전 전 소총 탄약 30발 상자 1개. CH01에는 수류탄과 산탄총을 배치하지 않는다.

### 수용 조건

조준·사격·재장전·회피 안내는 해당 행동을 수행하면 닫힌다. 안내를 닫지 않아도 전투는 진행 가능하다. 회복 학습과 교전 목표는 반드시 완료해야 한다. 모든 탄약을 소진해도 전투장 입구의 비상 보급 규칙으로 복구 가능하다. CH01 완료 후 재로드해도 소총이 사라지지 않는다.

## 4. CH02 — 사냥터 / Hunting Ground

### 공간

`집결지 → 갈림길 관측 지점 → 시신 운반 흔적 → 포획 둥지 → 현지 생존자 대피소 → 표본 채취 야영지`

갈림길은 낮은 강둑의 빠른 정면길과 높은 둑의 긴 우회길로 구성한다. 강은 얕아 수영을 요구하지 않는다. 둥지는 45×40m, 두 입구가 서로 보이지 않게 큰 뿌리로 분리한다. 출구는 전투 완료 후 열리는 생체 막이다.

### 미션 계약

| ID | 행동·완료 조건 | 필수 상태·보상 |
|---|---|---|
| M_C02_01 | 윤아 관측 지점 도달·인증 신호 확인 | CP_C02_00 뒤 새 목표 |
| M_C02_02 | 의무병 인식표·폭파 전문가 기록 확인 | 사망 상태 확정·CP_C02_01 |
| M_C02_03 | 포획 둥지의 잠금 장치 2개 해제, 지정 Stalker 6마리 처치 | 구조 공간 개방 |
| M_C02_04 | 현지 생존자 구출 상호작용 | 안전 이동 연출·회복 보급 |
| M_C02_05 | 마커스·엘레나 합류, 표본 1개 확보 | 산탄총 지급·CP_C02_02·챕터 완료 |

동시 Stalker는 최대 4, 전투 웨이브는 2+2+2다. 모방 음성은 2개 앵커에서 재생하며 임의의 진짜 구조 목표를 생성하지 않는다. 생존자를 구출하는 상호작용은 적 정리 후 가능하다. 이동 연출이 끝나면 생존자는 안전 지점에 직접 배치된다.

### 자원·변수

소총 30발 상자 3개, 권총 12발 1개, 회복약 2개. 산탄총은 챕터 말에 8발 장전+16발 예비로 고정 지급. 선택 기록 2개는 메인 출구와 독립적이다. 비상 보급은 전투장별 1회만 가능하다.

### 수용 조건

두 경로로 같은 목표에 도달한다. 죽은 대원의 상태와 구조 성공을 혼동하지 않는다. 구출 연출을 건너뛰어도 `civilianRescued=true`가 저장된다. 동료의 물리 위치가 출구 조건이 되지 않는다.

## 5. CH03 — 포식자 / Predators

### 공간

`부서진 군용 수송로 → Brute 투기장 A → 이동 연구 야영지 → 교란 기둥 지대 B → Wraith 개활지 C → 유적 입구`

A는 약 55×50m, 파괴 가능한 엄폐 3개와 파괴 불가 암석 2개를 둔다. Brute가 입구를 막아도 우회 가능한 순환 동선이 있다. C는 약 70×60m, 낮은 천장이 없는 개활지와 지붕 있는 안전 포켓 3개를 둔다. Wraith 비행 경로는 플레이어 이동 영역 밖까지 연결하되 사격 가능한 구간이 명확하다.

### 미션 계약

| ID | 행동·완료 조건 | 결과 |
|---|---|---|
| M_C03_01 | Brute 등장 지점 도달 | 아레나 문 닫힘·CP_C03_00 |
| M_C03_02 | Brute 1마리 처치 | 장갑 약점 학습·CP_C03_01 |
| M_C03_03 | 샘플 분석 단말 사용 | 유전적 유사성 공개·저격소총 지급 |
| M_C03_04 | 교란 기둥 2개 파괴 | Wraith 전투 활성·CP_C03_02 |
| M_C03_05 | Wraith 처치·유적 입구 진입 | 제한 통신 복구·CH04 해금 |

교란 기둥은 각각 체력 100, 장갑 없음. 적을 무한 소환하지 않는다. Brute와 Wraith를 같은 전투장에 동시에 배치하지 않는다. Wraith는 낮은 활공 경로 2개를 번갈아 사용하고 플레이어 바로 위로 순간이동하지 않는다.

### 자원

각 보스 전 소총 30발 상자 3개, 산탄총 8발 1개, 회복약 2개. 저격소총 5+15발은 분석 후 지급. Wraith 전 추가 저격탄 5발 상자 2개. 수류탄 2개는 Brute 전 고정 상자에서 첫 지급한다.

### 수용 조건

Brute 돌진으로 파괴되는 물체와 안전 암석이 구별된다. 장갑만 맞혀도 낮은 피해는 들어가지만 약점 사용이 유리하다. Wraith 교란 중에도 목표·체력·공격 예고·자막이 읽힌다. Wraith 사망 연출이 맵 밖에서 재생돼도 처치 이벤트가 기록된다.

## 6. CH04 — 고대의 비밀 / Ancient Secret

### 공간

`유적 전실 → 기억 장치의 방 → 봉인 터널 → 연구시설 기록실 → 방어 복도 → 비상 격벽·탈출 갱도`

유적은 아마존의 실제 원주민 유물과 혼동되지 않게 외계 비대칭·생체 구조로 설계한다. 기록실은 전투 없는 약 2분의 호흡을 제공한다. 탈출 갱도는 되돌아가도 마커스 구조를 시도하는 상호작용이 생기지 않는 구조다.

### 미션 계약

| ID | 행동·완료 조건 | 결과 |
|---|---|---|
| M_C04_01 | 기억 장치 2곳 순서 무관 활성 | 고대 기원 공개·CP_C04_01 |
| M_C04_02 | 시설 단말 기록 2개 확인 | 2027 신호·2039 작전 공개·CP_C04_02 |
| M_C04_03 | 준호의 데이터 복사 시작·지정 적 웨이브 모두 처치 | 복사 완료·탈출문 개방 |
| M_C04_04 | 격벽 제어기 가동·플레이어 탈출 앵커 진입 | 희생 연출·CP_C04_03 |
| M_C04_05 | 탈출 갱도 끝 도달 | 생존자 4명 상태·CH05 해금 |

CP_C04_00은 레벨 시작이다. 방어전은 Stalker 3+3마리와 Brute 1마리로 구성하며 동시 최대 4마리다. Brute는 첫 Stalker 웨이브 제거 후 등장한다. 복사 진행은 적 처치 단계와 연결해 시간만 기다리는 전투를 피한다.

### 자원

시설 입구에 소총 30발 4개, 산탄총 8발 2개, 회복약 2개. 방어전 중 고정 상자에 소총 60발·수류탄 2개. 아이템은 복사 시작 전 획득 가능하다. 데이터 단말에 접근했다고 전투를 즉시 시작하지 않고 별도 ‘복사 시작’ 상호작용을 요구한다.

### 수용 조건

원하는 순서로 기억 장치와 기록을 확인해도 각각 한 번만 집계된다. 텍스트 읽는 동안 적이 스폰되지 않는다. 마커스 희생을 건너뛴 저장에서도 CH05에서 마커스가 등장하지 않는다. 플레이어가 뒤늦게 탈출해도 NPC 경로 막힘으로 실패하지 않는다.

## 7. CH05 — 최후의 사냥 / Final Hunt

### 공간

`침식 협곡 → 교란기 설치 지점 → Overseer 방 A → 코어 내부 전실 → 신경 중추 방 B → 최종 설치 지점`

A는 약 60×50m, 엄폐를 돌아가는 두 측면길과 중앙 설치 지점이 있다. B는 약 65×65m의 3갈래 고리 동선. 신경 노드 3개가 서로 다른 높이의 낮은 단상에 있으며 점프 퍼즐을 요구하지 않는다. 밖에서 보이는 600m 코어와 내부 전투장의 스케일을 분리한다.

### 미션 계약

| ID | 행동·완료 조건 | 결과 |
|---|---|---|
| M_C05_01 | 재료 상자·준호 단말 상호작용 | 교란기 지급·CP_C05_00 상태 갱신 |
| M_C05_02 | Overseer 전투와 지원 이벤트 완료 | Overseer 사망·CP_C05_01 |
| M_C05_03 | 내부 전실 진입·선발대 연출 완료 | 최종 목표 준비 |
| M_C05_04 | ‘최종 작전 시작’ 상호작용 | 420초 타이머 시작·CP_C05_02 |
| M_C05_05 | 노드 3개 파괴·신경 중추에 폭발물 3초 설치 | 타이머 정지·최종 타격 연출 |
| M_C05_06 | 타격·에필로그 완료 또는 건너뛰기 | 캠페인 완료 저장 |

CP_C05_00은 시작 지점이며 준비 완료 후 장비·교란기 상태를 갱신한다. CP_C05_02는 **420초, 노드 0/3, 전투 시작 상태**를 저장한다. 최종 전투 중 별도 자동 저장을 하지 않는다. 사망·시간 초과·앱 재실행으로 이 체크포인트에 돌아오면 같은 자원과 420초로 재시작한다.

### 최종 전투 배치

- Overseer는 [05_GAMEPLAY.md](05_GAMEPLAY.md)의 3단계 보스 계약을 따른다. 일반 적 동시 상한 4.
- Mother Core는 한 번에 노드 1개가 노출된다. 파괴 시 다음 노드가 노출되고 바닥 패턴이 바뀐다.
- 각 노드 사이 Stalker 2마리씩, 총 4마리. 증원은 무한하지 않다. 보스 촉수는 일반 적 상한과 별도지만 한 번에 공격 1개만 판정한다.
- 마지막 노드 뒤 설치 지점까지 안전 이동 10초 이상을 확보한다. 설치 중 피격되면 중단되고 재시도 가능하다.
- 타이머 0은 실패. 완료 프레임에서는 입력 처리 후 설치 완료를 먼저 판정하고 미완료일 때만 시간 초과 처리한다.

### 자원

Overseer 전 소총 30발 5개·저격탄 5발 2개·회복약 3개·수류탄 2개. 코어 전실에서 탄약과 체력을 기본 상한까지 보충하고 회복약 3개를 보장한다. 코어 방 안에는 소총 30발 상자 3개를 노드별 1개씩 둔다. 설치용 폭발물은 전용 미션 아이템이며 수류탄 개수와 무관하다.

### 수용 조건

초반 플레이테스트에서 7분 중 순수 전투·이동 목표를 4~5분으로 조정해 여유를 둔다. 일시정지·컷신에는 타이머가 흐르지 않는다. 시간 초과 후 노드가 이미 파괴된 상태로 남지 않는다. 마지막 설치 직후 사망·중복 폭발·두 번의 엔딩이 발생하지 않는다.

## 8. 보급·소프트락 방지 공통 규칙

총알 낭비로 보스를 영구히 막지 않도록, 필수 전투장에는 `EmergencySupply`를 1개 둔다. 소총 총탄(장전+예비)이 10발 이하이고 전투가 진행 중이며 해당 상자를 아직 사용하지 않은 경우 소총 30발을 한 번 지급한다. 일반 보급과 별도 ID로 저장한다. 이것으로 여전히 완료가 어려우면 체크포인트 재시작이 가능하다. 무한 탄약이나 일반 적 무한 드롭으로 해결하지 않는다.

챕터 경계에서는 체력 100, 소총 총탄 최소 90발, 회복약 최소 1개를 보장하고 보유 상한 이상이면 추가하지 않는다. 다른 장비는 획득 상태와 잔량을 이월한다. 의도한 특수 보급은 각 챕터 표를 따른다.
