# Jungle JIM — 아트 디렉션·에셋 제작 가이드

> 버전 1.0 · 게임화 제안 · 대상: 모델·텍스처·애니메이션·UI·VFX·사운드 제작
> 연결: [캐릭터 실루엣](03_CHARACTERS.md) · [레벨 스케일](04_LEVEL_DESIGN.md)

## 1. 시각적 목표

**현실적인 군용 장비와 낯선 생체 구조가 충돌하는 습한 정글.** 초반은 자연의 녹색 속에서 위협을 찾아야 하고, 후반은 자연의 형태를 흉내 낸 외계 조직 속에서 인간의 흔적을 찾아야 한다.

프록시로도 완성 가능한 세미 리얼리즘을 기본 제안으로 삼는다. 사진 수준의 캐릭터 피부·광범위한 스캔 환경·전면 파괴는 필수 품질 조건이 아니다. 사격 대상과 길을 읽는 능력을 최우선으로 둔다.

## 2. 색·재질의 시각 언어

| 기능·대상 | 초기 팔레트 | 비색상 보조 단서 |
|---|---|---|
| 자연·안전 휴식 | 깊은 녹색 `#203B2C`, 이끼 `#64765A` | 안정된 수평 형태·자연음 |
| 인간 장비·진행 | 회색 `#566064`, 올리브 `#626A43` | 직선·표준 문자·작업등 |
| Stalker 감각·위장 틈 | 녹색 `#84D75D` | 작은 점군·관절 떨림·딸깍음 |
| Brute 노출 조직 | 주황 `#F29A45` | 큰 균열·벌어짐·증기 |
| 외계 지휘 신호 | 보라 `#AB7DE0` | 일정한 점멸·동심 패턴 |
| 고대 기억 장치 | 청록 `#56C6C1` | 느린 맥동·비대칭 부조 |
| 공격 위험 영역 | 붉은빛 `#E45C55` | 외곽선·진행 방향·음향 예고 |
| 상호작용 | 밝은 중성색 `#E7E4D7` | 아이콘·동사·키 표시 |

발광은 기능을 설명한다. 모든 배경 식물이 같은 강도로 빛나 약점을 숨기지 않게 한다. 장갑은 단단한 키틴의 거친 반사, 약점은 젖은 막과 유연한 움직임으로 차이를 준다. 초록 약점과 초록 정글은 밝기·모양·움직임으로 분리한다.

혈흔과 신체 손상은 전투 결과를 전달하는 수준으로 제한한다. 강한 잔혹성이나 인체 절단을 기본 필수 에셋으로 만들지 않는다. 등급은 출시 대상 지역과 실제 표현을 검토해 별도 확정한다.

### 캠페인 확장

주요 동료 4명과 보조 인물 공용 리그, Brute·Wraith·Overseer·중추, 산탄총·저격소총·수류탄·교란기, 생체 둥지·유적·연구시설 모듈, 파괴 엄폐 3종, 신경 노드·촉수, 엔딩용 변이 얼굴. 고유 에셋 수량은 레벨 그레이박스 확정 뒤 산정한다. 표의 예시 수를 무조건 늘리는 목표로 삼지 않는다.

## 5. 파일·명명·데이터 계약

논리 폴더 구조 제안이다. 엔진별 `Assets`·`Content`·`res` 구조 안에 대응시킨다.

```text
art/
  characters/taegeon/  characters/allies/
  enemies/stalker/ brute/ wraith/ overseer/ mother_core/
  environments/jungle/ ruins/ facility/ core/
  weapons/ props/ textures/ animations/ vfx/ ui/
audio/sfx/ ambience/ music/ voice/ko/
references/
licenses/
```

권장 이름: `{TYPE}_{SUBJECT}_{VARIANT}_{VERSION}`. 예: `SM_TreeKapok_A_01`, `SK_Stalker_01`, `AN_Stalker_Lunge_Windup`, `T_Stalker_BC`, `SFX_Rifle_Fire_01`, `UI_WeakpointHit_01`.

- `SM` 정적 메시, `SK` 스킨 메시, `AN` 애니메이션, `T` 텍스처, `M` 머티리얼.
- 이름은 ASCII·밑줄, 문서 설명은 한국어. 절대 로컬 경로나 제작자 개인 폴더에 의존하지 않는다.
- 소스와 엔진 변환본을 구분하고 원본을 보존한다. 생성·외부 구매·직접 제작 여부를 메타데이터로 남긴다.
- 원점은 바닥 중심을 기본으로 하고 무기는 손잡이 기준·장치류는 설치면 기준을 명시한다. 피벗·축 방향을 임의로 혼합하지 않는다.

에셋 매니페스트 필드:

| 필드 | 내용 |
|---|---|
| assetId / path | 안정 ID와 프로젝트 상대 경로 |
| type / chapter / priority | 형태·사용 장면·MVP 여부 |
| scale / axes / pivot | 실측 크기·전방/상방 축·피벗 |
| rig / clips / sockets | 리그, 클립, 총구·손·약점 소켓 |
| materials / lod / collision | 머티리얼 수, LOD, 충돌 형태 |
| origin / license / attribution | 제작 방식, 원문 출처, 사용 조건·표시 문구 |
| status / reviewer | 프록시·검토·승인, 검수자 |

## 6. 모델·리그·텍스처 기술 기준

엔진과 기준 PC를 확인하기 전의 예산 제안이다. 정확한 상한은 실제 프레임 측정으로 확정한다.

| 자산 | LOD0 목표 삼각형 | 기본 텍스처 | 머티리얼 슬롯 목표 |
|---|---:|---|---:|
| JIM·주요 동료 | 30k~50k | 2K, 얼굴 클로즈업만 4K 검토 | 4 이하 |
| Stalker | 20k~35k | 2K | 3 이하 |
| Brute·Overseer | 40k~60k | 2K~4K | 4 이하 |
| Wraith | 25k~45k | 2K | 3 이하 |
| 일반 소품 | 0.5k~8k | 512~2K | 1~2 |
| 나무·바위 모듈 | 2k~12k | 1K~2K 타일/아틀라스 | 1~2 |

- LOD1은 LOD0 대비 약 50%, LOD2는 약 20%를 시작점으로 한다. 전환 팝과 실루엣 붕괴를 점검한다.
- 메시 교환은 FBX 또는 glTF 중 프로젝트가 지원하는 포맷, 텍스처 소스 PNG/TGA를 사용한다. 엔진 전용 포맷으로 변환 후 확인한다.
- PBR은 BaseColor·Normal·Roughness·Metallic·AO·Emissive. 비금속 생체에 금속값 1을 일괄 적용하지 않는다. 채널 패킹은 프로젝트 규약을 따른다.
- 직물·장갑의 텍셀 밀도를 맞춘다. 젖은 재질이 플라스틱처럼 보이지 않게 거칠기를 조절한다.
- 플레이어와 적의 충돌은 단순 캡슐·상자로 시작하고 약점만 별도 히트박스. 풀 한 장마다 정밀 충돌을 만들지 않는다.
- 필수 소켓: `muzzle`, `hand_r`, `hand_l`, `weakpoint_*`. 표기법은 엔진 표준에 맞춰 통일한다.

## 7. 애니메이션·VFX 계약

전투 애니메이션은 `예고 → 유효 타격 구간 → 후딜`의 타이밍이 데이터와 일치해야 한다. 애니메이션 이벤트가 없거나 중복되어도 피해가 두 번 발생하지 않도록 게임 상태가 최종 권한을 갖는다.

| 대상 | 필수 클립·효과 |
|---|---|
| JIM | Idle·Walk·Run·AimMove·Fire·Reload·Dodge·Hit·Death·Interact |
| Stalker | Patrol·Camouflage·Reveal·Windup·Lunge·Recover·Hit·Death |
| Brute | Walk·ChargeWindup·Charge·Crash·WeakpointOpen·Slam·Death |
| Wraith | Circle·DiveWindup·Dive·Glide·Fall |
| Overseer | Signal·CastWindup·Cast·Sweep·Disrupted·Death |
| Core | Pulse·NodeOpen·NodeDestroyed·TentacleWarning·Strike·Collapse |

VFX는 예고와 충돌 결과를 우선 제작한다. 총구·폭발·코어 붕괴는 발광·입자 수를 제한하고 플레이어 시야를 가리지 않는다. 회피에는 무적을 암시하는 지속 실드 효과를 쓰지 않는다. 화면 흔들림은 설정으로 0까지 낮출 수 있다.

## 8. UI·한국어·사운드

- 배포·수정·재배포 권한이 확인된 한글 글꼴을 사용하고 라이선스를 동봉한다. 특정 폰트가 이미 설치돼 있다고 가정하지 않는다.
- HUD는 16:9 1080p를 기준으로, 720p와 16:10에서도 잘림을 확인한다. 화면 가장자리 5% 안전 영역 권장.
- 자막은 기본 2줄, 한 번에 읽을 수 있는 단위로 분리한다. 화자 이름과 중요 비언어음 `[나무 위에서 딸깍거림]` 등을 제공한다.
- 필수 UI 텍스트를 배경 이미지 안에 구워 넣지 않는다. 목표·튜토리얼은 번역 키로 관리한다.
- 총성은 순간적으로 강하지만 지속 앰비언스를 덮는 시간이 길지 않게 한다. 대화 시 앰비언스를 낮춘다.
- Stalker는 목소리의 어긋난 반복·관절 딸깍음, Brute는 낮은 발걸음, Wraith는 날개 마찰·간섭, Overseer는 규칙적 신호음으로 구별한다.
- 음원 소스는 WAV 48kHz를 권장하고 배포 압축 형식은 엔진 기준을 따른다. 공간음은 모노, 음악·비공간 배경은 스테레오를 기본으로 한다.
- 실제 인물의 목소리를 동의 없이 복제하지 않는다. 임시 음성은 출처와 임시 상태를 표시한다.

## 9. 콘셉트 이미지 제작 브리프

이 패키지에는 실제 콘셉트 이미지나 모델을 포함하지 않는다. 아래는 후속 제작에 사용할 이미지 브리프다. 원문에 나타난 이미지 검색 제안은 다운로드·라이선스 확보된 에셋으로 취급하지 않는다.

### 공통 조건

독창적 SF 밀리터리 생체 호러, 습한 아마존, 기능이 읽히는 외골격과 발광 기관. 기존 유명 영화·게임의 캐릭터·장비·로고를 그대로 복제하지 않는다. 이미지는 시각적 탐색 자료이며 실제 플레이 화면·납품 모델로 표시하지 않는다.

| 이미지 ID | 화면 구성·필수 요소 | 비율·용도 |
|---|---|---|
| REF_KEY_01 | 전경 JIM·소총, 중경 불타는 헬기, 후경 나무에 숨은 여섯 다리 Stalker | 16:9 키아트 |
| REF_CH01_01 | 여섯 날개 Wraith가 정글 상공 헬기 후방 로터를 공격 | 16:9 추락 스토리보드 |
| REF_ST_01 | Stalker 전·측·후면, 몸 길이 4m 표기, 약점·위장 상태 비교 | 3:2 크리처 시트 |
| REF_BR_01 | 5m Brute와 1.82m JIM의 스케일 비교, 장갑/관절 구분 | 3:2 크리처 시트 |
| REF_CH04_01 | 퇴적층 아래 외계 유적, 청록 부조, 현대 시설로 이어지는 통로 | 16:9 환경 |
| REF_CH05_01 | 600m 생체 코어 외경, 작은 헬기 실루엣으로 규모 표시 | 16:9 환경 |
| REF_CORE_01 | 내부 3개 노드·순환 동선·촉수 위험 영역을 표시한 방 | 16:9 레벨 페인트오버 |
| REF_TG_02 | 같은 JIM 얼굴, 오른쪽 눈 녹색·피부 아래 검은 혈관 | 1:1 에필로그 |

모델 시트는 중립 조명·단순 배경으로 제작한다. 컨셉의 멋보다 관절·뒤쪽 형태·크기 정보를 우선한다. 이미지 생성 결과는 다리/날개 수·손·무기·흉터·눈 방향을 사람이 확인한 뒤 승인한다.

## 10. 권리·품질 게이트

1. 외부 에셋을 넣기 전에 출처 URL·제작자·라이선스·상업 배포 및 수정 허용 여부를 매니페스트에 기록한다.
2. 권한을 확인할 수 없는 자산은 로컬 프록시로 바꾸고 출시에 포함하지 않는다. 인터넷에서 보인 이미지를 곧바로 게임 에셋으로 쓰지 않는다.
3. 원본/변환본 모두 누락 파일 없이 로드되고, 충돌·소켓·재질·애니메이션이 예상대로 연결된다.
4. 무채색·색각 보조 환경에서 적과 약점·위험 예고를 구분한다.
5. 10분 연속 플레이에서 이펙트가 누적되거나 음원이 중첩되지 않는다.
