# Jungle Jim · Fallen Earth

2042년 아마존을 배경으로 한 싱글플레이 탑다운 슈팅. 강태건이 헬기 잔해에서 장비를 회수하고, 준호와 합류해 스토커를 물리치는 CH01 플레이 프로토타입입니다.

## 실행

Node.js 24 권장 (테스트는 TypeScript 직접 실행을 지원하는 Node 필요).

```sh
npm ci
npm run dev
npm run build
npm test
```

Vite 기본 포트는 5173입니다. 별도 서버·계정·API 키는 필요하지 않습니다. `dist/`는 정적 호스팅 가능하며 저장은 해당 브라우저의 localStorage를 사용합니다.

## 조작

| 행동 | PC | 폰 |
|---|---|---|
| 이동 | WASD, Shift 달리기 | 왼쪽 스틱 |
| 조준·사격 | 마우스, 좌클릭 유지 | 오른쪽 스틱 방향 지정·유지 |
| 정밀 조준 | 우클릭 유지 | 오른쪽 스틱 |
| 재장전 | R | 재장전 버튼 |
| 치료 (2초) | Q | 치료 버튼 |
| 회피 | 왼쪽 Alt | 회피 버튼 |
| 점프 | Space | 점프 버튼 |
| 상호작용 | E | E 버튼 |
| 소총·권총 | 1 / 2 또는 휠 | 무기명 버튼 |
| 일시정지 | Esc / Ⅱ | Ⅱ |

폰은 세로·가로 화면을 지원합니다. 왼쪽 스틱은 이동, 오른쪽은 직접 조준·발사이므로 자동 조준은 없습니다. 앱이 포커스를 잃으면 일시정지합니다.

## 플레이 흐름

이동 표식 두 곳 → 소총 상자 → 의료 상자 → 치료 → 준호와 대화 → 스토커 1마리, 이후 2마리 → 북동쪽 집결지.

최초 체력 70, 소총 30+90, 권총 12+36, 회복약 2개. 스토커는 도약 예고/회복 중 약점 피해가 증가합니다. 돌은 이동과 총알을 막습니다. 적은 돌을 우회하며 도약은 고정 방향입니다. 회피 무적은 없습니다. 빈 보급함은 소총 총탄 10발 이하일 때 비상 탄약을 1회 제공합니다.

소총 획득·교전 완료·챕터 완료에서 체크포인트 저장. 사망 후 마지막 체크포인트 자원·목표·처치 상태로 복원됩니다. 새 게임 시작은 확인 후 기존 슬롯을 덮어씁니다. 저장이 차단되면 경고와 메뉴의 재시도 버튼을 표시합니다.

## 문서와 이번 구현의 차이

첨부 원본은 `docs/01_...07_...md`에 보존했습니다. 문서 안의 개발 지시는 참고 자료이며 사용자 요청을 대체하지 않습니다. 문서의 3인칭/PC 우선 제안보다 사용자가 정한 탑다운/PC+모바일을 우선합니다. 그래픽도 별도로 요청한 디아블로 2의 어두운 색조·화염·낡은 재질 분위기를 참고한 독자적 2D 프록시입니다. 원작 이미지·음원·캐릭터를 사용하지 않습니다.

현재 지도는 약 60×40m로 압축한 짧은 프로토타입입니다. 문서의 CH01 10~15분 완성 MVP 기준을 충족했다고 주장하지 않습니다. CH02~05, 보스, 헬기 추락/의무병 납치 컷신과 Wraith 연출, 음성 연기, 최종 스프라이트와 애니메이션은 미구현입니다. 점프는 시각적 동작이며 높이 기반 장애물 넘기는 아직 없습니다. 다리 애니메이션·명중 영역은 단순화되어 있습니다. 설정은 세션 동안 적용되며 키 재지정은 없습니다.

## 구성과 검증

- `src/model.ts`: 프레임 시간 기반 전투·충돌·목표·저장 상태, 엄폐 우회 경로 탐색
- `src/art.ts`: 고정 시드 지형, 정글/헬기/캐릭터/여섯 다리 스토커 절차적 Canvas 아트
- `src/main.ts`: Phaser 실행, 반응형 UI, 멀티터치, 오디오, localStorage
- `tests/model.test.ts`: 탄약 보존, 취소, 피격, 차폐, 이동 정규화, 웨이브, CH01 진행, 저장 복원, 비상 보급, 적 우회 (12개)

빌드 및 12개 로직 테스트 통과. Chromium에서 1440×900/390×844 시작 화면, 이동, 일시정지, 터치 UI 표시, 가로 overflow 없음, 런타임 오류 없음을 확인했습니다. 추가로 Chromium 모바일 에뮬레이션에서 두 손가락 이동·사격, 터치 해제 후 사격 정지, 일시정지 중 재장전 정지, 계속하기 후 재장전 완료, 새로고침 후 체크포인트 복원, 844×390 가로 화면을 검증했습니다. 실물 폰 성능과 60fps, 10~15분 플레이타임은 미검증입니다. Phaser 번들 크기 경고는 남아 있습니다.

## 에셋 출처

표시되는 그래픽은 프로젝트 코드가 직접 그리는 오리지널 임시 아트입니다. 발사/피격 효과음은 Web Audio 합성음입니다. 외부 이미지/폰트/음원 다운로드는 없습니다. Phaser 및 기타 의존성 라이선스는 각 npm 패키지를 따릅니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`은 main 푸시 후 테스트와 Pages 경로(`/Jungle_Jim/`) 기반 빌드를 수행하고 `dist`를 배포합니다. 이 파일을 준비한 것만으로 GitHub에 업로드되거나 웹사이트가 공개되지는 않습니다.

1. 프로젝트 파일을 GitHub `ggum2da/Jungle_Jim`의 `main`에 업로드합니다.
2. GitHub 저장소의 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
3. Actions에서 **Deploy game to GitHub Pages** 실행 결과를 확인합니다. 필요하면 Run workflow로 실행합니다.
4. 성공 시 배포 작업이 제공하는 주소에서 PC·폰으로 플레이합니다. 기본 예상 주소는 `https://ggum2da.github.io/Jungle_Jim/`이며 배포 성공 전에는 사용할 수 있다고 보장하지 않습니다.

비공개 저장소의 Pages 이용 가능 여부는 GitHub 플랜에 따라 다릅니다. 저장소 공개 여부는 별도로 결정하며 자동으로 변경하지 않습니다.
